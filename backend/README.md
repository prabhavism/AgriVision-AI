# AgriVision AI — Backend

## Setup
1. cd backend
2. python -m venv venv
3. source venv/Scripts/activate   (Windows Git Bash)
4. pip install -r requirements.txt

## Datasets
Place these in data/raw/ (not committed to git):
- Dataset 1: https://www.kaggle.com/datasets/zoya77/indian-historical-crop-yield-and-weather-data
- Dataset 2: https://www.kaggle.com/datasets/arjunyadav99/indian-agriculture-crop-production-and-yield
- Recommendation dataset: https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset
